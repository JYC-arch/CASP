# RCT 文獻評讀

依 CASP RCT Checklist（2024）英文原題編製，提供中文對照、文獻定位與評讀理由。

## 示範文獻

張雪玲、黃曉令、鍾玉珠（2023）。混合式衛教對全膝關節置換術老年病人疼痛及關節角度之成效。護理雜誌，70（2），45–55。https://doi.org/10.6224/JN.202304_70(2).07

## 功能

- 11 題 CASP 中英對照及考量點。
- 第 1 題以 PICO 與研究設計簡要呈現，對應 4 個文獻位置。
- 評讀理由以使用者提供的 Markdown 為主，依教師確認的刪除原則整理為 45 個列點；每點下方提供對應的文獻位置按鈕。保留文獻資料與必要查核，不含延伸推論、符合計畫分析或自行推算的信賴區間。
- 「名詞解釋」位於評讀理由之前，並在引導觀察模式中可先行展開。分派隱匿與盲法參照課堂資料補充時間、對象與角色。
- 講解後點選「顯示判讀結果」，呈現題號、中文完整題目及答案。結果區不重述理由。
- 第 4 題整體判讀為「否」，另列 4(a) 無法判斷、4(b) 否、4(c) 否。
- 全站共 57 個題目與文獻位置的對應。同一來源可供多個列點共用；PDF 註記依座標去重，避免重複疊色。文獻未報告的事項以「查核範圍」標示按鈕。
- 各題使用不同顏色；「本題標註 PDF」保留完整 11 頁研究，只標示本題查核範圍。
- 電腦版文獻閱讀區固定於畫面，可獨立縮放及捲動。窄螢幕提供「對照文獻」按鈕。

## 內容版本

中文題目、判讀及理由以「CASP_RCT_2024_中文版評讀_混合式衛教TKR.md」（評讀日期：2026 年 11 月 19 日）為主，依教師確認的刪除原則整理。第 1 題保留已確認的精簡 PICO；其餘理由以列點呈現。原始 Markdown 文件未修改。

各題判讀只在點選結果後顯示，切換題目或回到引導觀察時重新隱藏。「評讀總結」提供各題結果總覽，不重複理由，不加總為研究品質分數。

## 使用方式

開啟 index.html，並保留同層 JS、CSS 與 assets 資料夾。亦可透過 GitHub Pages 發布，無需安裝套件。網址 #q1 至 #q11 可連至指定題目。Alt + 左／右方向鍵切換題目，Esc 關閉視窗。

## 名詞解釋參考

第 2 題隨機分派、分派隱匿及與盲法的對照，參照課堂資料《RCT說明》PDF 第 11、14–15 頁；第 4 題盲法與單盲、雙盲、三盲，參照第 15 頁及 CASP 2024 第 4(a)–4(c) 題。單盲、雙盲、三盲的角色組合依課堂圖示呈現，實際評讀仍依文章交代的角色。名詞解釋與研究證據分別呈現，判讀結果維持在講解後揭露。
