# RCT 文獻評讀

依 CASP RCT Checklist（2024）英文原題編製，提供中文對照、文獻定位與評讀解析。

## 示範文獻

張雪玲、黃曉令、鍾玉珠（2023）。混合式衛教對全膝關節置換術老年病人疼痛及關節角度之成效。護理雜誌，70（2），45–55。https://doi.org/10.6224/JN.202304_70(2).07

## 功能

- 11 題 CASP 中英對照及考量點。
- 各題文獻頁碼、段落及表圖定位。
- 不同題目以固定色彩標示，並保留題號及文字標籤。
- 「引導觀察」供原文查證；「示範解析」呈現教師解析，講解後點選「顯示判讀結果」才揭露參考答案與評讀紀錄範例。切換題目後結果重新隱藏。
- 每題以「是／否／無法判斷」呈現參考結果，部分題目另列分項判讀。
- 研究方法說明、評讀紀錄範例及整體評讀總結。
- 電腦版文獻閱讀區固定於畫面，解析可持續捲動；文獻本身可獨立縮放及捲動。窄螢幕提供「對照文獻」按鈕。

## 評讀結果版本

中文題目、考量點、判讀結果、理由及文獻位置依「CASP_RCT_2024_中文版評讀_混合式衛教TKR.md」更新（評讀日期：2026 年 11 月 19 日）。每題「評讀理由原文」保留該文件的完整內容。第 4 題分為 4(a)、4(b)、4(c)，其餘保留 1–11 題導覽。判讀總結共列 13 個項目，不加總為研究品質分數。

## 使用方式

開啟 index.html，並保留同層 JS、CSS 與 assets 資料夾。本網頁亦可透過 GitHub Pages 發布，無需安裝套件。

網址 #q1 至 #q11 可連至指定題目。Alt + 左／右方向鍵切換題目，Esc 關閉視窗。
